VERIFICATION METHOD

核验方法

公开版本记录与实时许可状态分开处理，保留原表字段、统计日期和来源差异。

核对什么

核对网站服务名称、登记地址和许可证编号，按原表服务项边界保存。应用程序、公众账号、论坛和直播项目不混入网站表。名单没有给出的单位、服务类型或域名保持空缺，不根据名称推测补入。

如何处理日期和版本

来源发布日期、名单统计截止日期、实际核验日期分别记录。原表只写到月份时，保留月份。不同版本名称或证号发生变化时，保留两版证据并复核，不自动解释为注销或换主体。

哪些记录暂不公开

原件未取得、仅有PDF文本而未完成版面复核、官方链尚未确认、登记域名缺失、统计日期不明、明确字段差异及同域不同证号线索，均进入待审资料。本轮1326条候选中，898条公开，428条暂缓。

如何理解查询结果

同一个许可证可能对应多个网站，同名也可能对应不同服务项。查询未找到记录，可能来自覆盖缺口、来源发布时间、名称差异或暂缓审核，不能据此认定网站违法。

公开数据范围

当前公开数据为静态版本记录，非全国完整现行许可名录。可下载898条公开记录JSON。数据文件也明确保留当前许可有效性未单独确认的状态。
