关于我们

面向公众的独立媒体资料整理与检索项目。

项目与运营主体

中国媒体身份资料库由荆门暗猫网络科技有限公司建设与运营，围绕互联网新闻信息服务网站名单整理可追溯的公开版本记录。本项目不属于政府机关，也未宣称获得官方授权认证。

业务关联与数据支持

运营公司同时运营暗传播（PR Channel），两者存在明确运营关联。本资料库与商业媒体报价目录分开维护，收录与审核以公开证据为依据，不因合作关系或商业发布服务而改变。

感谢暗传播为资料整理提供数据支持。许可事实及名单版本以国家和地方许可机关的原始公开来源为准。

维护与局限

本轮整理了1326条候选，898条对应版本记录通过公开审核；9省仍缺可复核原件。数据更新存在时差，不提供实时许可有效性保证、媒体权威排名或商业渠道授权结论。

纠错与隐私

如发现名称、域名或编号差异，应先提供可追溯的原始证据。当前公开受理渠道尚未配置，网站不设反馈收集表单，也不收集或储存访客提交信息。详见纠错说明与隐私说明。
