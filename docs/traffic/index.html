数据来源与适用边界

数据来源

日均 IP、日均 PV、Alexa 国内排名、百度来路区间与备案主体均取自爱站网（aizhan.com/cha/）与站长之家公开查询页，逐域名于 2026-11-24 抓取；每条记录标注数据源与实测日期。报价表后台自报的「权重」不构成流量证据，不进本层。

判定漏斗中的位置

资源判定按互斥顺序：①许可名单命中 → 资质媒体；②否则垂直赛道命中 → 行业媒体；③否则第三方实测流量达标 → 流量渠道；④都不满足 → 无价值/待淘汰。流量渠道是兜底层、非必选项：无资质又非垂直、且没有第三方实测流量的站点，不因「有流量」被合理化保留。

明确不构成

本层不证明新闻资质、不做许可有效性判断、不代表行业归属、不构成商业合作背书。备案主体疑似官方媒体而许可库无对应记录的条目标为「资质待核」，须另到媒体查询核对；主域命中许可记录也只作交叉提示，不改变本层数据性质。

对外数据

逐条明细见流量渠道数据；域名比对索引见traffic-index.json（域名→名称/分级/类型）。该索引与新闻资质域名索引、行业收录索引来源与证明力不同，不得互相替代。
