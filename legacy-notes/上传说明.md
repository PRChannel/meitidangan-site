# 全国新增候选提取 · GitHub 增量更新

本包只新增4个文件，不替换已有网站和采集工作流。文件相对现有仓库根目录：

- `nationwide_extract.py`
- `data/baseline_400.csv`（当前基线，非官方最新全量；只用来排除旧记录）
- `data/sources_32.json`（现有32个来源条目，部分无法访问）
- `.github/workflows/nationwide-extract.yml`

操作：用 GitHub Desktop 的 Repository → Show in Finder 打开原仓库，将本包**里面的四个文件按目录复制**，Commit to main → Push origin。

随后到 GitHub Actions，手动运行 **Nationwide media extraction and review (manual)**。运行完成后下载 `nationwide-media-extraction-review` 报告 ZIP 并提交给助手分析。

结果包括：`全国候选记录.csv`、`待审核新增.csv`、`域名冲突.csv`、`32地区来源状态.csv`、`附件处理状态.csv`、`证据索引.json`、`SUMMARY.json` 和下载成功的原始网页/附件证据。

**重要限制**：这不是已核验的全国全量数据库。本版不自动添加任何数据到网站，不能据此判断媒体现行资质和可靠性。即使程序成功执行，结果仍可能包含待补的官方来源、图片/PDF、动态页面及其他无法解析的格式。`待审核新增` 一律需要人工确认。对于证据不齐全或名称/证号匹配不充分的记录，禁止自动上线。

文件下载有8MB上限、HTTPS要求，不尝试绕过访问限制；对大文件、PDF与扫描文件需单独补充适配器。
