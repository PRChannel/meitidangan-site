# 中国媒体身份资料库：全国统一审核（离线基线版）

本包用于将**既有400条基线**与**最新179条候选**进行统一匹配和审核列队。它不是完整全国1,700+条的数据库；还需要从未覆盖地区采集原始名单。默认**不向公开网页写入任何数据**。

## 当前核查结果
- 400条基线；179条候选；32条来源运行状态。
- 名称、许可编号与域名均一致：158条。
- 西藏19条原来源未列域名，故不能比较域名。
- 域名字段有差异：2条，需要核查原始官方资料；绝不自动改值。
- 这179条在基线中均找到名称和许可证号对应项；本轮新增0条。

## 在 GitHub 运行
将 `unify_registry.py`、`data/` 目录，以及 `.github/workflows/unified-audit.yml` 放进现有仓库对应位置。保持既有 `docs/`、`pilot.yml`、`national.yml`、`fasttrack.yml` 不变。GitHub Desktop 中 Commit 后 Push。在 Actions 中手动运行 `Unified nationwide registry audit (manual)`，下载 `unified-national-audit` 报告。

也可以在本地解压后运行 `python3 unify_registry.py`；`out/` 已包含当前运行的结果，不需要先使用 GitHub。

## 审核边界
- 同一许可证可能关联多个网站或域名，不能仅凭许可证号合并。
- 本次比对不证明实时许可有效或站点实际正常运行。
- 缺失域名不补猜；冲突保持待审。
- 数据来源及样本限定于此前已经收集的结果，不是新的全国联网采集。

下一轮应先获取尚未结构化的其他地区官方名单，然后把新的候选 CSV 纳入同一审核流程，而非逐城市做单独数据库。
