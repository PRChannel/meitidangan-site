媒体档案 meitidangan.com | GitHub Pages 正式站点部署包

1. 解压本压缩包。
2. 将解压后目录内全部文件（不是外层目录）上传至公开仓库 PRChannel/meitidangan-site 的 main 分支根目录。
3. 仓库 Settings -> Pages：Deploy from a branch, main, /(root)。
4. 先使用 https://prchannel.github.io/meitidangan-site/ 检查页面？注意：本包已针对自定义根域名采用绝对路径，正式使用前务必先在 Pages 中设置 Custom domain 为 meitidangan.com 并完成DNS，才能正常加载CSS与媒体链接。
5. 在 Pages -> Custom domain 输入 meitidangan.com 并保存。域名注册商按 GitHub 官方文档配置根域名A记录；GitHub Pages 指示DNS生效后启用 Enforce HTTPS。
6. 本包仅公开400条原有基线记录，不含内部爬虫/工作流/待审候选。
7. 上线前核对关于我们中的运营主体，补充真实有效联系渠道以及适用的备案/合规事项。
8. 搜索页面为浏览器端JSON检索，页面SEO由各档案独立HTML、canonical、sitemap、JSON-LD提供。
9. 官方来源URL为基线原始资料所载，不代表已经实时检查来源有效性。
